The ALASHO Digital Platform

ALASHO is a Nigerian luxury fashion house focused on bespoke tailoring, contemporary menswear, traditional craftsmanship and wardrobe consulting.

This repository contains the source code for the ALASHO digital platform.

Getting Started

Prerequisites

Install the following:

Node.js
Git
npm
Installation

Clone the repository:

git clone https://github.com/murphyedward602-ship-it/alasho.git

Navigate into the project:

cd alasho

Install dependencies:

npm install

Environment Configuration

Create your local environment configuration using .env.example.

Add the required credentials:

GEMINI_API_KEY=your_gemini_api_key

APP_URL=http://localhost:3000

Never commit private API keys or production secrets to GitHub.

Running the Application

Start the development server:

npm run dev

Production Build

npm run build

Start Production Server

npm run start
